# 🌦️ Weather App

A responsive weather application that provides real-time weather information for any city using a weather API.

## 🚀 Features

* 🔍 Search weather by city name
* 🌡️ Displays current temperature
* 💨 Shows wind speed
* 💧 Displays humidity levels
* ☁️ Weather condition information
* 📱 Responsive design for desktop and mobile devices
* ⚡ Fast and user-friendly interface

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* Weather API
* Font Awesome

## ⚙️ Installation

1. Clone the repository

```bash
git clone https://github.com/mahi414/weather-app.git
```

2. Navigate to the project directory

```bash
cd weather-app
```

3. Open `index.html` in your browser.

## 🔑 API Setup

1. Get an API key from your weather service provider.
2. Open `script.js`.
3. Replace the placeholder API key with your own:

```javascript
const API_KEY = "ec858dd1770d8e373e3f923c55510e9a";
```
